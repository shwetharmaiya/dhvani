Dhvani – Kannada Text-to-Speech Web App 🎙️

Dhvani is a Kannada-only Text-to-Speech (TTS) web application built using Next.js, powered by Google Cloud Text-to-Speech.
It converts Kannada text into natural-sounding speech and works reliably across Windows, macOS, Android, and iOS.

✅ Kannada-only text-to-speech (kn-IN)

✅ High-quality Google Neural (WaveNet) voice

✅ Works on Windows 10/11 (no OS Kannada voice required)

✅ MP3 audio playback

✅ Built with Next.js (App Router) and TypeScript

✅ Tailwind CSS UI

✅ Secure server-side API (no key exposure)


🏗️ Tech Stack

Next.js 13+ (App Router)

TypeScript

Tailwind CSS

Google Cloud Text-to-Speech API

Node.js 18+
